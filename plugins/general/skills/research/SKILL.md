---
name: research
description: Investigate a question against primary sources and capture the findings as a Markdown file in the repo. Use when the user wants a topic or API facts researched, or reading legwork delegated to a background agent.
---

Spin up a **background agent** to do the research, so you keep working while it reads.

Its job:

1. Investigate the question against **primary sources** — official docs, source code, specs, first-party APIs. Follow every claim back to the source that owns it.
2. Write the findings to a single Markdown file, citing each claim's source.
3. Save it where the repo already keeps such notes; if there is no such convention, choose one. Report the path either way.
